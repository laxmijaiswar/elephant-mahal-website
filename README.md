# elephant-mahal-website

Family-friendly restaurant website for Elephant Mahal in Neral, Karjat - featuring menu highlights, reviews, and contact information.

This repository now contains a ready-to-publish static website (index.html).

How to preview locally

- Open index.html in your browser (double-click or run a local server):
  - Python 3: `python -m http.server 8000` then visit http://localhost:8000

Publishing with GitHub Pages

1. Go to this repository's Settings → Pages.
2. Under "Source", choose the `main` branch and `/ (root)` folder, then Save.
3. After a minute, your site will be available at:
   `https://<your-github-username>.github.io/elephant-mahal-website/`
